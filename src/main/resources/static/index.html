Date Convertor

Convert any date between the English (Gregorian / AD) and the Nepali (Bikram Sambat / BS) calendars — instantly, in your browser.

BS 1970 – 2100AD 1913-04-13 – 2044-04-12
Format: YYYY/MM/DD

English date (AD)

REST API

The same conversion is available as a JSON API:

curl -X POST http://localhost:8080/api/convert/ad-to-bs \
  -H "Content-Type: application/json" \
  -d '{"date": "2026-08-05"}'
# {"adDate":"2026-08-05","bsDate":"2083/04/20"}

curl -X POST http://localhost:8080/api/convert/bs-to-ad \
  -H "Content-Type: application/json" \
  -d '{"date": "2083/04/20"}'
# {"bsDate":"2083/04/20","adDate":"2026-08-05"}

Invalid dates return 400 with an {"error": "..."} message.
